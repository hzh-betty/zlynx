## 实现

1. 超过 1 MiB 的大块按精确页数复用，不切分/合并。单块最多 8 MiB，空闲总预算 16 MiB；超预算驱逐最早归还的块，超过 8 MiB 直接解除映射。普通 1–128 页桶不扩张。大块映射不带永久缓存标记，归还时清理整个范围，包括 override 对齐块的附加页登记。显式回收同时覆盖大块缓存。
2. 常量初始化的 TLS 缓存指针使热路径直接取得当前线程缓存；首次访问继续调用既有 `get_thread_cache()` 注册退出钩子，晚期 TLS/pthread/静态析构仍取得同一个已关闭缓存。GCC/Clang 沿用 initial-exec，其他编译器回退原 getter。
3. 受管 `free` 和搬迁式 `realloc` 使用已验证 Span 进入内部释放 helper，移除重复 PageMap 查询；保留边界检查、页锁、errno、递归保护、对齐头、bootstrap 和 foreign libc。第一版在 4 KiB 八线程长对照中下降 9.3%，随后将常量初始化的递归深度计数器也改为原始 TLS，移除 C++ TLS 初始化包装器检查，保持 guard 增减语义，再验证最终结果。
4. 尚未整段建议回收的完全空闲页达到 32 MiB，且累计归还至少 8 MiB 页时触发自动回收。单轮最多检查 32 个 Span、建议回收 8 MiB，空桶访问最多一轮 129 个桶。跨轮保存位置，分配/切分/合并/驱逐前推进游标。只在整段页归还路径触发，不增加逐对象 TLS 热路径扫描。没有后台线程；停止分配/释放后不会继续回收，不主动清理其他线程缓存。

回收保留虚拟映射，`MADV_DONTNEED` 成功才计入统计。计数器受页锁保护，自动回收保留 errno。字节和检查次数有上限，系统调用耗时没有硬性上限；累计建议字节数允许复用后再次计入。

## 测量条件

Clang 21.1.8、C++17、共享库、Release `-O3 -DNDEBUG -g -fno-omit-frame-pointer`，关闭 coverage，不使用 Sanitizer/LTO/PGO 测性能。i5-12500H / WSL2 Linux，详情见 `metadata.json`。原报告 `probe.cc` 未修改，固定输入、每 worker 预热 200 批、原绑核与计时边界；正式探针绑核错误均为零。配对版本交替运行，每场景五次，表列百万次“分配+释放”/秒的中位数及时间 CV。仓库原有 single/cross/churn benchmark 没有绑核，高波动结果须谨慎解释。

源码阶段：`baseline` = 上轮 4 KiB 优化；`large` = 大对象复用；`tls` = 缓存指针快路径；`override` = 查询精简第一版；`final` = 自动回收第一版；`guard` = 最终版本，另含递归深度 TLS 精简。不将不同时间或不同参数的中位数混作同一对照。

## 自动回收收益与成本

对照尚未启用回收的 `override` 和最终 `guard`。压力探针触碰 128×1 MiB 全部页，逐块释放，再分配并触碰全部页；绑 CPU 0，五次配对中位数：

| 指标 | 回收前策略 | 自动回收 |
| --- | --- | --- |
| 释放后 RSS | 132.63 MiB | 28.61 MiB |
| 128 块释放总耗时 | 0.025 ms | 5.229 ms |
| 单块释放 p99 | 0.503 μs | 502.931 μs |
| 自动建议回收范围 | 0 | 104 MiB |
| 再分配并触碰全部页 | 10.81 ms | 44.03 ms |
| 再触页 minor faults | 0 | 26624 |

回收组释放总耗时范围 3.00–6.86 ms，单块最大耗时范围 0.33–1.01 ms。用释放和再次触页开销换取空闲 RSS，单轮工作量上限不保证固定延迟。

原始 32768×4 KiB / 128 MiB 探针的最终五次对照：释放后 RSS 133.81 → 38.55 MiB；再调用显式回收后 RSS 约 5.9 MiB，复用后的全块内容检查均通过。策略不保证完全空闲页总量始终小于 32 MiB，建议范围字节数也不等于实际 RSS 降幅。

## 验证与兼容性

- 最终 Release：17/17，包含真实共享 override、冷启动、late TLS/pthread/static destructor、shutdown 后分配释放、对齐/外部 libc、realloc 失败与并发存活对象。
- ASan/UBSan：14/14 非 override 模块测试；全局 malloc 替换与 Sanitizer 拦截冲突，三个 override 目标由 Release 检查。
- TSan：8/8，包含新增 PageCache、TransferCache、PageMap、CentralCache、ThreadCache、memory、并发和冷启动。
- 新测试覆盖缓存预算及驱逐时存活块、超上限解除映射、自动回收门槛/单轮字节预算/errno、计数器与统计一致性、游标跨分配/切分/合并/大块驱逐的有效性。
- `git diff --check` 通过。最终所有编译输入与被测 `guard` 快照 SHA-256 一致。归档源码在独立目录重建后另通过 17/17 Release，见 `reproduction-check.log` 和 `reproduced-guard-tests.xml`。

公开函数签名不变，但 PageCache 私有布局 8392 → 8496 字节；Span 仍为 64 字节，ThreadCache 仍为 9168 字节。公开内联接口在调用方生成单例存储并访问内部字段，必须重新编译所有消费目标，不能混用旧头文件对象与新版共享库。沿用 initial-exec 启动链接约束，运行后动态加载未保证。实测范围为 Linux/WSL2、Clang、共享库；其他编译器/平台未验证。
